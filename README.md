# WhatsApp Chat

Тестовое задание на позицию Frontend React Developer.

Веб-приложение для обмена текстовыми сообщениями WhatsApp через GREEN-API.

## Технологии

- React
- TypeScript
- Vite
- CSS
- GREEN-API

## Реализованные функции

- Подключение к WhatsApp через GREEN-API
- Проверка авторизации инстанса
- Создание чата по номеру телефона
- Отправка текстовых сообщений
- Автоматическое получение входящих сообщений каждые 7 секунд при открытом чате
- Отображение входящих и исходящих сообщений
- Список сохранённых чатов
- Сохранение истории переписки в localStorage

## Установка и запуск

1. Клонировать репозиторий.
2. Открыть папку проекта в терминале.
3. Установить зависимости: `npm install`
4. Запустить приложение: `npm run dev`
5. Открыть адрес, который покажет Vite (обычно `http://localhost:5173/`).

## Подключение GREEN-API

Для работы приложения необходим авторизованный WhatsApp-инстанс GREEN-API.

На экране подключения нужно ввести:

- `apiUrl` — адрес сервера из настроек GREEN-API
- `idInstance` — идентификатор инстанса
- `apiTokenInstance` — токен доступа к API

После успешного подключения можно открыть чат по номеру телефона с кодом страны.

## Проверка проекта

- `npm run lint` — проверка кода.
- `npm run build` — сборка приложения.

## Ограничения

История сообщений сохраняется локально в браузере и не синхронизируется с полной историей WhatsApp.

Приложение является учебным прототипом. API-токен используется для запросов из браузера, поэтому текущая архитектура не предназначена для публичного производственного использования.
